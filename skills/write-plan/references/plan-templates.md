# Шаблоны плана реализации

## Заголовок документа плана

```markdown
# План реализации: [Название фичи]

> **Для агентов:** Используй скилл execute-plan для реализации этого плана задача за задачей. Шаги используют синтаксис чекбоксов (`- [ ]`) для отслеживания.

**Цель:** [Одно предложение описывающее что это строит]

**Архитектура:** [2-3 предложения о подходе]

**Ключевые файлы / стек:** [Основные технологии/конфиги — берётся из CLAUDE.md проекта]

---
```

## Структура задачи (TDD-шаги)

Универсальный шаблон. Подставь язык и команды своего стека (см. `CLAUDE.md`).

````markdown
### Задача N: [Название компонента]

**Файлы:**
- Создать: `точный/путь/к/файлу.<ext>`
- Изменить: `точный/путь/к/существующему.<ext>`
- Тест: `точный/путь/к/тесту.<ext>`

- [ ] **Шаг 1: Написать падающий тест**

```<lang>
<реальный код теста, проверяющий конкретное поведение>
```

- [ ] **Шаг 2: Запустить тест и убедиться что он падает**

Запуск: `<команда запуска теста>`
Ожидается: FAILED с конкретным сообщением (например, «функция не определена»)

- [ ] **Шаг 3: Написать минимальную реализацию**

```<lang>
<реальный код реализации>
```

- [ ] **Шаг 4: Запустить тест и убедиться что он проходит**

Запуск: `<команда теста>`
Ожидается: SUCCESS

- [ ] **Шаг 5: Убедиться что тесты затронутого кода проходят**

Запуск: `<команда тестов затронутого кода и архитектурных тестов из CLAUDE.md>`
Ожидается: всё зелёное
````

В шаге 5 перечисли конкретные тест-классы, файлы или маски пакетов / модулей: тесты изменённого кода
и кода, который его использует. Тесты незатронутого кода в план не включай (см. «Проверка задачи
перед завершением» в `CLAUDE.md`).

## Примеры конкретизации команд

Бери реальные команды из `CLAUDE.md` / конфигов проекта. Примеры для разных стеков:

```bash
# JVM (Gradle / Maven)
./gradlew test --tests "com.example.orders.*"
mvn test -Dtest='OrderServiceTest'

# JavaScript / TypeScript
npx vitest run src/orders
npx jest src/orders/create-order.test.ts

# Python
pytest tests/orders -k "create_order"

# Go
go test ./internal/orders/... -run TestCreateOrder

# Rust
cargo test orders::create

# Линтеры / статический анализ
./gradlew detekt | npx eslint src | ruff check . | golangci-lint run | cargo clippy
```
