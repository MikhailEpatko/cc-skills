## Ведение задач в папке `ai`

- Папка `ai/` — единое место для артефактов по задачам.
- Идентификатор задачи: `<формат, например PROJ-1234>`.
- Для каждой задачи: `ai/<TASK-ID>/`; подзадачи — `ai/<TASK-ID>-<N>/`.
- Запрещено изменять артефакты ранее выполненных задач.

Файлы задачи:

1. `task.md` — постановка задачи пользователем.
2. `spec.md` — спецификация.
3. `plan.md` — план реализации.
4. `plan.log.md` — лог подготовки плана.
